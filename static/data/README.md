# SafeVLA-Bench Website Data Snapshot

This directory mirrors the lightweight result artifacts used by the current SafeVLA-Bench project page.

- `aggregated.csv`: headline per-model/per-suite metrics.
- `aggregated_with_ci.csv`: headline metrics with Wilson and bootstrap confidence intervals.
- `aggregated.json`: JSON version of the aggregate table.
- `aggregated_dropped.json`: runs excluded during aggregation.
- `threshold_sensitivity.csv`: recomputed metrics under tighter and relaxed threshold variants.
- `failure_modes.csv`: per-cell failure-mode breakdown.
- `failure_modes_summary.json`: compact failure-mode summary.
- `safevla-results.zip`: all of the files above as one download.

The full raw-state rollout archive is larger than this website bundle and is not mirrored here.
